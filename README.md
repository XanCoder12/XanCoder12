## `01` — About Me

I'm **Muhammad Yusuf Akram**, a developer from Bandung, Indonesia, interested in understanding and building software beyond the application layer.

I enjoy exploring how systems work internally—from memory management and filesystems to compilers, networking, and operating system architecture. My interests also extend to backend engineering, web applications, and embedded systems, where software interacts directly with hardware.

I prefer learning by building, experimenting, debugging, and examining the underlying mechanisms rather than treating technology as a black box.

**My philosophy:** understand the fundamentals, build practical things, and keep improving.

- **Primary interest:** Systems programming and operating system development.
- **Also exploring:** Backend engineering, compilers, networking, and embedded systems.
- **Daily environment:** Linux, terminal-centric workflows, and open-source tools.
- **Current direction:** Strengthening my foundations in systems engineering through practical projects.
